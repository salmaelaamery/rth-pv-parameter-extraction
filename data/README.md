# Benchmark data

The numerical I-V benchmark values used in this study are embedded directly in the corresponding MATLAB experiment scripts and reproduced in the article supplementary material.

- Shell SM55: 25-point reference I-V data at STC, cited in the article.
- RTC France 57 mm solar cell: 26 measured I-V points at 33 degrees C, cited in the article.
- Photowatt-PWP201: 25-point I-V convention at 45 degrees C, cited in the article.

No third-party dataset file is redistributed separately here. When reusing a benchmark, consult and cite its original source listed in the published article.
